CONTROLS (desktop)

Classic schemeLeft-click selects; with units selected, left-click ground to move / enemy to attack. Right-click deselects.
Modern schemeLeft-click selects, right-click commands.
DragBox-select (Shift adds)   Double-click: all of that type on screen
Ctrl+A / Ctrl+DSelect whole army / deselect
A / P / D / SAttack-move / Patrol / Guard area / Stop   Esc cancels   F9 pauses (skirmish)
Shift + commandQueue waypoints (move, attack-move, patrol)
Q / E (EE)Select whole army / select same type on screen (press twice: whole map)
Q W E R T Y U ICommand panel (build, train, research)
Z X C V B / GGeneral powers / fire superweapon
Ctrl/Shift + 1-9Assign group; 1-9 recall (tap twice to jump)
Wheel / Arrows / edgesZoom / scroll   Space: base

CONTROLS (phone / tablet)

TapSelect unit/building. With units selected, tap ground to move, tap enemy to attack.
Drag / pinchPan the map / zoom. Long-press then drag (or the ▭ Box button) to box-select.
Side buttons⚔ select army, A-Move, Stop, ✕ deselect, ⌂ base, zoom. ★ Powers opens General powers.
